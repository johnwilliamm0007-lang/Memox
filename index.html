About your data

Live prices are sourced from Binance Spot public market data. EGP values are estimates using a Binance P2P USDT sell-side reference, when available.

P2P offers vary by payment method, order limits and merchant. The displayed rate is not a guaranteed execution price. Missing or blocked prices are never replaced with invented values.

Your portfolio is saved in this browser using local storage. It is not synced across devices. No Binance password or API key is required.
